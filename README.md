# Motif Finder

A textile-reference search workspace.

## Phase 1
- Upload / drag-drop / paste a reference image
- Crop only the motif using a full crop editor
- Zoom, rotate and reset
- Create a clean search-reference crop
- Copy the crop to clipboard or download PNG
- Launch official reverse-image search destinations
- Local recent-reference history
- Mobile + desktop responsive UI

## Search coverage
Phase 1 does not pretend to search sources automatically. It launches the official external services and prepares the crop for paste/upload.

Planned next phases:
1. Automatic web match cards through supported APIs
2. Exact / partial / similar grouping
3. Shutterstock computer-vision search
4. TinEye commercial search
5. Textile-specific ranking and vector/high-resolution filters
